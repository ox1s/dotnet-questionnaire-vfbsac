# Система Анкетирования

Платформа для проведения анонимного анкетирования студентов, сотрудников и работодателей с целью оценки качества образования. Система заменяет бумажные анкеты, сохраняя привычную методику расчета баллов.

Задача создания и манипулирования анкетами и пользователями лежит на администраторе

Из реализованного:
[x] манипуляция c группами
[x] манипуляция анкетами
[x] выключение анкет
[x] манипуляция с справочниками (преподаватели, специальности, специализации, филиалы кафедр)
[ ] наниматели
[ ] закрытие/открытие анкет
